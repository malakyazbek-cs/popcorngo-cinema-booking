# 🍿 PopcornGo — Grab Your Seat & Snack!

## 📌 About
PopcornGo is an Android cinema booking application developed using Java, XML, and MySQL. It allows users to browse movies, reserve seats, order snacks, and manage their tickets. It also provides an admin dashboard for managing movies, showtimes, snacks, bookings, and sales reports.

## 🛠️ Technologies Used
- **Java** — Android application development.
- **XML** — Designing Android user interfaces.
- **MySQL** — Storing and managing application data.
- **Android Studio** — Development environment.
- **RecyclerView** — Displaying movies, showtimes, snacks, and other dynamic lists.

## ✨ Features

### 👤 User Features
- **Authentication:** Register and log in to an account.
- **Browse Movies:** Explore now-showing, coming-soon, and old movies.
- **Movie Details:** View movie information, showtimes, screen numbers, and ticket prices.
- **Seat Selection:** Select available seats and check seat availability.
- **Ticket Booking:** Reserve seats and automatically calculate ticket prices.
- **Snack Ordering:** Browse snacks, select quantities, and add them to an existing booking.
- **My Tickets:** View booked movies, screening details, prices, and booking statuses.
- **Booking Management:** Pay for pending bookings using the application balance or cancel eligible bookings.
- **Profile Management:** Update account information, manage credit card details, and check or add funds.

### 🔐 Admin Features
- **Dashboard:** View movie totals, booking statistics, seat occupancy, and low-stock alerts.
- **Movie Management:** Add, edit, view, and delete movies.
- **Showtime Management:** Schedule screenings and manage dates, times, screens, and ticket prices.
- **Snack Management:** Manage snack details, prices, images, and inventory.
- **Booking Management:** View and filter bookings by status, date, movie, and user.
- **Reports:** View bookings by movie, monthly revenue, and best-selling snacks.

## 👥 User Roles

- **Regular User:** Browse movies, reserve seats, order snacks, manage tickets, and update their profile.
- **Administrator:** Manage movies, showtimes, snacks, bookings, inventory, and sales reports.

## ⚙️ How It Works

1. **Login and Registration:** Users log in or create an account. The application redirects them to the appropriate dashboard based on their account type.
2. **Movie Browsing:** Users explore available movies and select a movie to view its details and showtimes.
3. **Seat Reservation:** Users select a showtime, choose available seats, and confirm their booking. The system checks seat availability to prevent double-booking.
4. **Snack Ordering:** Users browse available snacks, select a booking, choose quantities, and add snacks while respecting stock limits.
5. **Booking Management:** Users review their bookings, check ticket details, pay for pending bookings, or cancel eligible bookings.
6. **Administration:** Admins manage movie information, showtimes, snack inventory, and customer bookings.
7. **Reports:** The admin dashboard provides statistics about bookings, seat occupancy, revenue, and snack sales.
